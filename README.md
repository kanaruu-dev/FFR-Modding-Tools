# FFR Modding Tools

Releases and the update feed for FFR Modding Tools, a desktop modding toolkit for
FINAL FANTASY RESONANCE.

- Download: https://www.nexusmods.com/finalfantasyresonance/mods/1?tab=files
- `latest.json` is what the app reads to offer an update. It holds the newest released
  version and the page to get it from.
